Master Thesis · University of Münster · Nov 2025

Efficient Vision Attention Mechanisms for Dense Prediction

PDF Code

Summary

This work examines architectural choices for Vision Transformers to perform efficient pixel-wise regression. Experiments study changing the attention mechanism, patch size, encoder design, decoder design, and gradient checkpointing. The variants are compared in terms of their runtime, perceptual quality, and quantitative performance.

Bachelor Thesis · University of Münster · Dec 2022

Combining Deep Feature Extraction with Locality-Sensitive Hashing for Reverse Image Search

PDF Code

Summary

This work presents a system to perform fast reverse image search on hundreds thousands of input images. First, a Vision Transformer is trained with the self-DIstillation with NO labels (DINO) framework to produce vector embeddings. Then, Locality-Sensitive Hashing (LSH) is used to perform an approximate nearest neighbors search on the embeddings.
